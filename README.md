# 剧本演绎 App - 项目文档（整理版）

## 1. 项目简介
这是一款基于 Flutter 的剧本演绎 App，**适配 iOS/Android 双端**。用户可选择不同剧本与角色进行沉浸式角色扮演。App 提供丰富的剧本类型与角色选择，支持快速匹配与历史记录，旨在提升互动娱乐体验。**MVP 版本剧本由产品团队原创提供。**

## 2. 目标平台与版本范围
- **目标平台**：iOS / Android（Flutter 双端适配）
- **版本阶段**：MVP 1.0
- **定位**：沉浸式多人/单人角色扮演与剧情互动

## 4. 核心功能模块

### 4.1 用户体系（基础支撑）
- **第三方登录**：支持 Apple ID（Sign in with Apple）、Google、Facebook 一键登录
- **邮箱登录**：支持邮箱 + 密码注册/登录
- **游客模式**：允许游客体验，后续可绑定账号
- **账号绑定**：游客账号可绑定邮箱/手机号/第三方账号

### 4.2 首页
#### 4.2.1 剧本分类页（Script）
- **剧本列表**：推荐剧本（封面、名称、类型、时长）
- **可玩剧本**：用户可参与的剧本（封面、名称、类型、时长）

#### 4.2.2 角色分类页（Characters）
- **角色分类**：主角/反派/配角/群演
- **角色信息**：头像、名称、特点标签（如：侠客、学霸、校草）

### 4.3 剧本详情模块
- **基本信息**：简介、角色列表、难度
- **角色选择**：选择可扮演角色
- **剧本评论**：仅支持剧本一级评论（无回复/点赞），仅可发送文字评论，保留举报入口并进行敏感词审核（替换为「[已屏蔽]」）

### 4.4 角色详情页面
- **基本信息**：头像、名字、特点标签、难易程度、标志性台词
- **性格/特点标签**：详细标签描述
- **人物背景描述**：背景故事与相关信息
- **演绎雷达图**：演技、逻辑、沉浸、感情、节奏等维度
- **主要人物关系**：人物关系网络

### 4.5 剧场（快速匹配）
- **匹配入口**：首页一键启动（仅匹配“角色”）
- **偏好优先**：优先匹配注册偏好；无偏好则随机匹配角色
- **分类策略（MVP）**：为避免内容稀缺导致失败，MVP 不提供匹配分类设置
- **匹配结果**：展示角色详情、剧本片段
- **重新匹配**：用户关闭角色信息后可重新匹配
- **退出匹配**：匹配过程中退出则停止匹配流程
- **匹配超时策略**：匹配超过 10 秒未返回结果，则自动切换为随机匹配并提示用户
- **重复角色去重权重**：对最近 24 小时已匹配过的角色降低权重，优先匹配未出现角色

### 4.6 历史记录
- **游戏记录**：仅保留玩过的剧本与扮演角色，按时间线展示（不做日期分组）
- **结局标签**：未完成 / 已完成
- **未完成剧本**：可继续玩（从存档点恢复，对手角色由 AI 接管）
- **已完成剧本**：可再次游玩
- **分享记录**：可分享角色信息、剧本信息（不含评论）、扮演完成结果至外部平台（默认轻度脱敏：隐藏结局、角色结局与剧本关键剧情；一键分享无需设置）  
  - **关键剧情判定标准（示例）**：  
    - 涉及**真相揭示**、**核心反转**、**凶手/犯人身份**、**关键证据**的描述  
    - 导致结局分支变化的**关键选择**或**剧情节点**  
    - 直接点明剧本核心秘密、隐藏设定或最终目标的内容
- **游戏内招募分享**：游戏中可分享至招募板块，新加入用户进入后可选择无人扮演角色
- **角色招募列表**：用于展示招募信息（MVP 低优先级，可能删除）；与历史记录同属主页面 Tab 第三个分区切换

### 4.7 个人中心
- **个人资料**：头像、昵称、ID 展示与编辑
- **剧本创作中心入口**：MVP 仅做预热 Banner
- **偏好设置**：与剧本/角色标签挂钩（如：悬疑、爱情、惊悚；侦探、罪犯等）
- **游戏统计**：总游戏时长、完成剧本数、解锁结局数
- **基础设置**：通知开关、隐私设置（简版）、黑名单列表（可解除拉黑）
- **帮助反馈**：帮助文档与反馈入口

### 4.8 消息系统
- **平台信息推送**：标题栏入口，接收系统通知/活动信息
- **用户私信（IM）**：不建立好友关系，仅会话模式，支持拉黑与举报（拉黑后互不可见）
- **剧本邀请/组队成功消息**：支持邀请与组队成功通知
- **红点提示**：未读消息数量提示
- **推送卡片**：顶部信息提示卡
- **推送卡操作**：
  - 点击进入信息列表
  - 点击关闭按钮
  - 超时自动消失
- **红点持久**：用户查看前持续提示
- **私信能力范围**：
  - 基础功能：文字、图片、emoji
  - 付费/VIP 功能：语音通话、视频通话

### 4.9 详情页面入口
- **剧本详情入口**：剧本卡片点击进入
- **角色详情入口**：角色卡片点击进入

### 4.10 首启动方案（冷启动剧本）
- **触发时机**：用户完成账户注册后进入剧场，直接开始角色扮演
- **冷启动剧本形态**：2 人本，AI 扮演对手角色
- **引导目标**：
  - 完成用户信息注册引导
  - 一级平台核心宣讲
  - 新用户使用指导
- **流程步骤（示例）**：
  1. **欢迎页**：展示首启动提示与时长预告  
     - 文案：`欢迎进入平行剧场，体验另一种人生`  
  2. **信息补全**：由 AI 扮演的角色在对话中引导补全用户名/性别/生日（必填），以及昵称/头像/偏好标签（可选）  
     - 说明：娱乐化社交平台需进行年龄段合规审核，生日为必填项  
     - 文案：`在对话中完善信息，匹配更合适的角色`  
     - **年龄段合规提示文案（示例）**：  
       - `为保障平台合规与体验，请填写真实生日（将用于年龄段审核）`  
     - **年龄校验规则（示例）**：  
       - 必填生日，且不可晚于当前日期  
       - 年龄 < 18：不允许使用，提示“未成年人暂不支持使用本应用”  
       - ≥ 18：正常使用全部功能
     - **对话式引导文案（示例）**：  
       - AI：`欢迎来到平行剧场。先告诉我你的用户名。`  
       - 用户：输入用户名  
       - AI：`你的性别是？`  
       - 用户：选择性别  
       - AI：`为了合规，请填写生日。`  
       - 用户：选择生日  
       - AI：`很好。想让我如何称呼你？`  
       - 用户：输入昵称（可跳过）  
       - AI：`给我一个能代表你的头像吧。`  
       - 用户：上传头像 / 跳过  
       - AI：`最后一个问题：你更喜欢哪种题材？`  
       - 用户：选择标签（如：悬疑、爱情、惊悚）  
       - AI：`收到。你的角色已准备就绪，故事马上开始。`  
     - **分镜节奏（示例）**：  
       1) 1 句对话 → 弹出输入框（用户名，必填）  
       2) 1 句对话 → 弹出性别选择（必填）  
       3) 1 句对话 → 弹出生日选择（必填）  
       4) 1 句对话 → 弹出输入框（昵称，可跳过）  
       5) 1 句鼓励反馈 → 弹出头像选择  
       6) 1 句引导 → 弹出偏好标签多选  
       7) 1 句确认 → 自动进入匹配/开场提示
  3. **平台核心宣讲**：卡片式说明玩法与价值  
     - 文案：`选角色、入剧场、沉浸演绎，解锁不同结局`  
  4. **冷启动匹配**：系统分配新手 2 人本与 AI 对手  
     - 文案：`已为你匹配新手剧本，AI 对手已就位`  
  5. **角色确认**：展示角色简介与开场须知  
     - 文案：`你的角色：{角色名}，准备开始第一幕`  
  6. **演绎教学**：高亮“台词/选择/推进”交互  
     - 文案：`根据提示选择行动，推动剧情发展`  
  7. **完成引导**：结算页提示更多玩法  
     - 文案：`完成新手剧本，去首页探索更多剧本`  
     - 按钮：`去首页选剧本` / `再体验一次`
- **引导页埋点（示例）**：
  - `cold_start_view`：进入冷启动流程
  - `cold_start_profile_submit`：提交信息补全
  - `cold_start_tutorial_step`：引导步骤完成（附 step_id）
  - `cold_start_finish`：完成冷启动剧本
  - `cold_start_skip`：跳过引导
- **转化指标（示例）**：
  - 冷启动完成率 = 完成冷启动人数 / 进入冷启动人数
  - 信息补全转化 = 提交信息人数 / 进入信息补全页人数
  - 首次留存引导达成 = 完成冷启动且进入首页人数 / 完成冷启动人数
- **跳过规则**：
  - 引导页右上角提供“跳过”入口（最低保留 1 次提示）
  - 用户跳过后直接进入首页，可在个人中心再次进入新手引导
  - 已完成冷启动的用户不再强制进入，仅在版本更新时提示体验

### 4.11 玩法入口与游戏场景
- **入口一（剧本 → 角色）**：选择剧本 → 进入剧本详情 → 选择角色 → 开始游戏
- **入口二（角色 → 游戏）**：从角色列表选择角色 → 进入角色详情 → 开始游戏  
  - 角色分类（MVP）：主角 / 反派 / 配角 / 群演
- **游戏场景**：IM 聊天形式，包含玩家角色与 **AI DM**（负责引导与节奏把控）
- **开场提示**：进入游戏前展示 **Action 提示**（玩法要点/注意事项）
- **演绎交互**：
  - 发送文字消息
  - 发送语音消息（语音转文字后展示）
- **结束详情页**：
  - 完成演绎星级
  - 用户扮演角色信息
  - 演技/逻辑/沉浸/感情/节奏雷达图与评分
  - 游戏内亮点台词

## 5. 技术实现（Flutter）

### 5.1 前端技术栈
- **Flutter**：跨端 UI 框架
- **Dart**：主要开发语言
- **Material / Cupertino**：双端设计风格适配
- **Flutter 布局体系**：Row/Column/Stack 等组件布局

### 5.2 核心功能实现
#### 轮播功能
- 使用 PageView/AnimatedSwitcher 实现卡片轮播
- 自动播放，每张停留 5 秒
- 指示器显示当前卡片位置

#### 卡片布局
- 响应式卡片设计
- 卡片包含封面、名称、类型标签、时长信息
- 支持横向滚动列表（ListView/SingleChildScrollView）

#### 双端优化
- 统一触摸体验与交互手势
- 适配 iOS/Android 屏幕尺寸与设计规范
- 处理平台差异（字体、返回手势、权限提示）

## 8. 开发注意事项

### 8.1 双端适配
- 交互元素适合触摸操作
- 字体大小与间距可读性优化
- 适配不同 iOS/Android 设备屏幕

### 8.2 性能优化
- 图片加载与缓存优化
- 减少 DOM 操作，提升响应速度
- 轮播与滚动保持流畅

### 8.3 用户体验
- 简化注册登录流程
- 清晰导航与操作指引
- 明确错误提示与状态反馈

### 8.4 举报流程
- **入口**：剧本评论/私信消息/用户资料页均提供举报入口
- **步骤**：选择原因 → 补充说明/证据 → 提交 → 系统回执
- **处理时效**：普通举报 24-48 小时内处理，严重违规优先处理
- **结果通知**：站内通知反馈处理结果，支持用户申诉

### 8.5 违规处理规则
- **轻度违规**（如轻微骚扰、低质刷屏）：内容删除 + 警告/短期禁言
- **中度违规**（如重复骚扰、引战辱骂）：内容删除 + 7-30 天禁言
- **严重违规**（如涉政暴恐、色情、诈骗）：内容删除 + 永久封禁
- **累犯处理**：多次违规按等级升级处罚；保留违规记录

### 8.6 VIP 权益与定价（示例）
- **基础功能**：文字/图片/emoji 私信（免费）
- **VIP 权益**：语音通话、视频通话（含赠送通话时长）
- **通话计费**：赠送时长耗尽后，语音/视频通话按分钟消耗内部货币
- **定价**：USD $4.99/月，$12.99/季，$39.99/年（含税与地区定价按应用商店规则调整）

### 8.7 内部货币（示例）
- **用途**：解锁剧本、特殊角色、视频/语音通话按分钟计费
- **购买方式**：支持单独购买，不依赖 VIP
- **与 VIP 的关系**：VIP 赠送通话时长；时长耗尽后使用内部货币继续通话
- **充值档位（示例）**：USD $0.99 / $4.99 / $9.99 / $19.99 / $49.99（对应货币数量随活动调整）
- **货币有效期**：自购买之日起 24 个月有效；赠送币有效期 6 个月
- **赠送币规则**：节日活动/新手礼包/连续登录可获得赠送币；赠送币优先消耗
- **促销折扣**：充值折扣、限时礼包、首充双倍等活动可变更币量或价格
- **退款规则**：
  - 未消耗货币可在购买后 14 天内申请退款（以应用商店政策为准）
  - 已消耗货币不支持退款
  - 违规封禁导致账户不可用的，余额不予退还

### 8.8 隐私政策、用户授权与数据保留（示例）
- **隐私政策展示**：首启动与设置页提供隐私政策入口，首次使用需确认同意
- **用户授权**：
  - **基础信息**：账号注册信息、偏好标签、匹配记录用于服务提供
  - **设备权限**：相机/相册/麦克风/通知等按需请求并说明用途
  - **可撤回**：用户可在系统设置或应用内撤回授权，不影响基础浏览
- **数据保留**：
  - **账号数据**：在用户账户存续期间保留，用户注销后在 30 天内完成删除或匿名化
  - **消息与评论**：用于提供服务与风控，默认保留不超过 180 天（合规要求除外）
  - **运营日志**：用于稳定性与安全分析，默认保留不超过 12 个月
  - **购买记录**：按应用商店与财税合规要求保留
- **用户权利**：提供数据访问、更正、删除与注销入口

### 10.2 运营与体验风险（已明确方案）
1. **匹配数据稀缺风险**：MVP 角色量少导致重复是客观限制。  
   - **兜底与宣导**：提示“内容产出中”，提供跳转首页选剧本，并宣传下版本“用户自创剧本”。  
   - **UI 文案（示例）**：  
     - 标题：`内容还在产出中`  
     - 描述：`当前角色较少，已为你准备更多内容，敬请期待。`  
     - 宣传：`下个版本将支持用户自创剧本，敬请关注。`  
   - **交互与跳转**：  
     - 主按钮：`去首页选剧本` → 跳转首页剧本列表  
     - 次按钮：`稍后再试` → 关闭弹窗并停止匹配  
     - 入口处补充提示 Banner，点击可进入“创作中心预热页”或“功能预告”页
2. **消息推送频控与退订**：需明确推送频率、免打扰与退订机制。  
   - **主动推送范围**：新私信、未完成剧本有角色进入的开场提示、App 信息推送  
   - **频控规则（示例）**：  
     - 营销/运营类：每日不超过 1 条、每周不超过 3 条  
     - 业务提醒类：每日不超过 3 条（含开场提示）  
     - 深夜免打扰：22:00–09:00 不推送（紧急系统消息除外）  
   - **退订与免打扰**：  
     - 应用内可按类型关闭（私信/剧本/活动）  
     - 支持一键全部关闭与系统通知引导  
   - **用户唤起推送方案（示例）**：  
     - 触发条件：连续 7 天未活跃  
     - 频率：每周不超过 1 次，最多连续 4 周  
     - 内容：推新剧本/新角色/创作中心预告，避免剧透  
     - 退出：用户点击“关闭此类推送”立即生效
3. **异常与空态处理**：网络异常、无剧本、无角色等空态需统一规范；匹配结果为空仅在网络异常时触发，其他情况按匹配机制兜底处理。  
   - **空态文案（示例）**：  
     - 网络异常：`网络开小差了，检查连接后再试`  
     - 无剧本：`当前暂无剧本，内容正在加紧产出`  
     - 无角色：`当前暂无可选角色，更多角色即将上线`

### 10.3 安全与合规措施（已补充）
1. **三方登录与账号绑定安全**：采用 Apple/Google/Facebook 标准 OAuth 流程；Token 仅存 Keychain/Keystore；明确账号合并、解绑与找回规则。
2. **UGC 风控**：评论仅文字并进行敏感词替换「[已屏蔽]」；保留举报入口；私信支持拉黑（互不可见）与举报；必要时接入人工审核。
3. **隐私与数据合规**：已补充隐私政策、用户授权与数据保留说明；支持权限撤回与数据访问/删除/注销。
4. **分享功能权限与脱敏**：默认轻度脱敏（隐藏结局、角色结局与关键剧情），一键分享无需用户设置。
5. **内容注入防护**：UGC 展示统一转义与白名单过滤，禁止脚本与危险链接，避免 XSS/脚本注入。
